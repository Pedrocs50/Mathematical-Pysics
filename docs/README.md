## Sobre estes textos

- Eles foram montados a partir de emails, slides, apostila e artigos. **Não são transcrição das aulas.** Cada nota tem um espaço "Minhas anotações" para você completar.
- Trechos marcados como **Complemento** são explicação de apoio que não está no material da disciplina.
- Os PDFs dos professores não ficam no repositório. Procure nos anexos dos emails.
- As equações usam LaTeX e aparecem formatadas no GitHub e na pré-visualização do VS Code (`Ctrl+Shift+V`).
